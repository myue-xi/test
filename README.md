# C++ Epoll + 协程网络编程项目

这是一个基于 epoll 和协程的 C++ 网络编程示例项目，展示了如何使用协程简化网络编程。

## 项目结构

```
.
├── include/          # 头文件目录
│   ├── coroutine.h  # 协程实现
│   ├── scheduler.h  # 协程调度器 + Epoll事件循环
│   └── net.h        # 协程化网络操作封装
├── src/             # 源代码目录
│   ├── echo_server.cpp  # Echo服务器
│   └── echo_client.cpp  # Echo客户端
├── Makefile         # 构建脚本
└── README.md        # 说明文档
```

## 核心组件

### 1. 协程 (coroutine.h)
- 基于 ucontext 实现的协程
- 支持创建、恢复、让出等基本操作
- 支持协程状态管理

### 2. 协程调度器 (scheduler.h)
- 单例模式的调度器
- 集成了 epoll 事件循环
- 支持协程与 IO 事件的协同工作

### 3. 网络工具 (net.h)
- 封装了协程化的网络操作
- 支持 TCP 监听、连接、读写等操作
- 自动处理非阻塞 IO 和事件等待

## 编译和运行

### 编译
```bash
make
```

### 运行服务器
```bash
# 使用默认端口9000
./server

# 指定端口
./server 9001
```

### 运行客户端
```bash
# 连接到默认端口9000
./client

# 连接到指定端口
./client 9001
```

## 示例代码说明

### Echo 服务器
- 监听指定端口
- 为每个客户端连接创建一个协程
- 实现简单的 echo 功能（收到什么数据就返回什么）

### Echo 客户端
- 连接到服务器
- 发送测试消息
- 接收并显示回显数据
- 展示协程的基本使用

## 特点

1. **高并发**：基于 epoll 和协程，可以轻松处理大量并发连接
2. **简洁**：使用协程简化异步编程，避免回调地狱
3. **高效**：协程切换开销远小于线程切换
4. **易用**：提供封装好的网络操作接口

## 注意事项

1. 本项目仅用于演示和学习目的
2. 生产环境使用需要考虑更多的错误处理和边界情况
3. 协程的堆栈大小需要根据实际需求调整
